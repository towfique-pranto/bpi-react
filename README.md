# BPI React

A small React project built with GitHub Copilot AI assistance to test generative AI for coding.

## Overview

The primary goal of this project is to investigate how AI-powered code generation can streamline the development lifecycle for small-scale applications.

## Core Tech Stack

Framework: React (Functional Components & Hooks)

Build Tool: Vite for HMR (Hot Module Replacement)

AI Engine: GitHub Copilot (Logic generation & UI scaffolding)

## Getting Started

1. Clone the repository:
   `git clone https://github.com/towfique-pranto/bpi-react.git`
2. Change Directories:
   `cd bpi-react`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`
